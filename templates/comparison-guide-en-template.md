# Comparisons Guide

> Comparison pages are for comparing tools, approaches, repositories, or arguments after enough source notes exist.

## How to Use

1. Collect at least two comparable source summaries.
2. Define the comparison question.
3. Ask the AI to create a comparison page with evidence linked back to source summaries.

## Suggested Format

- Objects being compared
- Use case
- Comparison dimensions
- Table
- Recommendation
- Evidence sources
