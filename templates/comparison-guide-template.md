# 对比分析说明

> 对比分析用于比较多个工具、方案、观点或仓库，不是初始化时自动生成结论。

## 怎么使用

1. 先积累至少两个可比较的素材摘要。
2. 明确比较问题，例如“哪个更适合本机安装”“哪个更适合做浏览器自动化”。
3. 让 AI 生成对比分析页，结论必须引用已有素材摘要。

## 适合对比的内容

- 同类 GitHub 仓库
- 同类工具或框架
- 两种实现方案
- 两篇文章的观点差异

## 建议格式

- 比较对象
- 使用场景
- 关键维度
- 对比表
- 结论和建议
- 证据来源
